Syntax & Code Examples

let name = "N+"*
let age = 13*

if age >= 13 {
    print("Hello!")*
}
fn add(a: int, b: int) -> int {
    return a + b*
}
// For loop
for i in 1..6 {
    print(i)*
}

// While loop
while score < 10 {
    score = score + 1*
}

Statement Terminators

N+ supports explicit line terminators to keep syntax unambiguous:

  • * is the preferred standard terminator.
  • ! is an alternative terminator.
print("Hello")*
print("World")!
